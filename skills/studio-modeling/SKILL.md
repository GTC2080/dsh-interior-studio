# 尺寸与构件建模

把客户意图变成可编辑、可测量的方案。使用当前 `studio_context` 与 `studio_draw` 的能力和目录。完整官方 PTC 工具仍可用于代码、资料与建模实验，操作以真实执行结果为依据；参数接口未暴露不代表 Blender 没有该能力。

## 按需求加载

用户只给出日常描述、条件不完整或不知道如何提需求时，先加载 studio-design-brief，由助手整理已知条件并分步询问关键缺项；已有明确修改不重复访谈。

需要曲面、真实厚度/内腔、复杂装配、收口或替换粗占位时，加载 studio-detail-modeling。它负责 Blender 制作、GLB 回写、细节检查与清理；本技能继续负责尺寸明确的 CAD 和参数结构。

PTC 内的 studio 工具返回 JSON 字符串，先 JSON.parse，再在程序内按 key 取完整对象、测量与筛选；只返回本轮需要的摘要。不要直接打印完整场景，日志截断不是可用的完整依据。

## 从需求到形体

- 先区分客户硬性要求、已确认事实、可自主设计部分、未知内容。保留要求的数量、形状、尺寸及功能；占位物、近似造型、缺少原稿的图文必须标明。关键尺寸冲突时列出计算与取舍，不能悄悄缩短、删除或移走对象。
- 为对象分配稳定且有意义的 key。按真实几何分解构件：盒体、圆柱、带孔/圆角的轮廓拉伸、文字。组合用 assembly 表达，但组合内穿插仍需解释，不能借组合名让问题消失。已有对象重绘时保持 key 与未要求变动的属性。
- 圆角使用工具的 cornerRadius 或轮廓点第三项半径。闭合内孔必须完全位于轮廓内；接触边界的敞口画入外轮廓。用 passage 表达无框、无玻璃、无门扇的通道。文字只能还原文字，不能冒充图像、商标或角色原画。
- 墙用于室内空间边界，开口附着于完整墙路径，rooms.point 只标记房间内部。不要用缺失墙线代替门，也不要用普通目录资产冒充尺寸明确的定制造型。

## 单位、基准与变换

- 长度、坐标、标高均为米。绘图工具 rotation 为度，scene.rotation/rotationEuler 为弧度；重绘先换算。局部坐标经旋转再平移到世界坐标，不能直接把局部宽深当作旋转后的世界占地。
- 室内总长宽默认 outside，中心线从外缘退半墙厚；明确中心线才用 centerline；场地用 site。净尺寸只引用 measurements.rooms.clear 的实算结果；字段为空时不能拿外包或中心线面积替代。
- box/cylinder.position 是底面中心；extrusion/text.position 是轮廓原点。xy 沿 +Z、xz 沿 +Y、yz 沿 +X 拉伸。目录物件绘图 z 是底部标高，scene.position 则是三维中心。抬升支承面时同步核对上方对象的底高。
- scene 的轮廓已按圆弧约 0.2mm 弦误差采样，重新绘制时不要凭采样点猜原始圆角；必要时引用原需求参数，最终核对实算外包络。

## 提交与迭代

1. 读取当前版本、权限和草案；按允许范围提交完整方案。studio_propose 仅适合简单尺寸提案，不能代替具体设计。
2. 检查返回的 measurements、furnitureReview、componentReview 及 issues；绘图失败时按具体对象和原因修正后重试。
3. 调用 `studio_review` 核对关键尺寸、数量与有功能意义的连接，按 `studio-space-review` 执行。避免仅修改说明而不修改实际几何。
4. 修正后比对未要求变动的部位，保留假设与尚未解决的冲突。草案需用户在右侧确认才能替换三维；不能替用户确认。

形体、布局或材质修改先回写CAD草案并确认，再生成CAD图册和三维。只有机位改变且没有待确认草案时，studio_refine直接保存机位版本，返回changedViews；无需重复确认或导出未变CAD/几何。渲染通过依赖校验复用模型，旧图保留实际生成来源和当前适用性。未确认的几何草案仍阻止建模与出图。PTC 创建局部素材可以服务于草案，不得用独立 blend 或图片绕过正式流程。

CAD 工作区提供 A3 技术图纸，平面按 +1.200 m 剖切。含目录物件、导入模型或文字的四向立面读取实际网格特征边，消隐按不大于5mm步长采样；简单参数场景使用解析消隐。图像饰面不自动描线，平面中的精细对象仍用包络。尺寸以毫米标注，标高以米表示；组合外包含间隔，不是单件下料尺寸。

本地界面支持当前图纸 SVG 和五视图 DXF 图册导出。新正式任务的 plan.dxf 是通过 cadAudit 绑定的五视图图册；草案和旧任务中的同名文件可能仍是原始参考 CAD，不能混称。studio_export可导出指定位置的X/Y实际网格剖面及设计构件CSV；不补造未建模节点、下料规格或工艺，缺项逐项说明。

## 工具与验证衔接

几何计算优先加载studio-geometry并使用studio_geometry。圆角、圆弧、偏移和尺寸取工具实算结果；结果valid=false时修正原因，不静默改变客户尺寸。保存constraints并用整场/组合范围计入地台与附属件。
