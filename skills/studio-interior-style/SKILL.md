# 风格、材料与光的共同设计

先看本工程的用途、自然光、已有硬装、品牌、预算线索和用户偏好。风格名是交流起点；不强制给项目贴标签，不把某种市场流行、暖光或无主灯当作普遍正确答案。

按需读取 [风格与搭配卡](references/style-and-materials.md)，选择相关条目即可。输出能制作的组合：主要表面和家具/构件用什么材料、色彩怎样分主次、光从哪里来、哪个局部承担重点，以及为什么适合当前活动。不能只堆叠“高级灰、奶油、侘寂”等形容词。

材料占比、圆角、纹理重复与粗糙度数值如需建议，应说明适用对象和依据，不能把当前建议改称通用规则。未提供品牌规范时，新增颜色只是候选配色，不称为客户的品牌色。

区分现有材质、用户提供的素材和你建议的新材料。按 studio_context.materials 的实际能力选择；需要准确的新纹理时通过既有图片饰面或 GLB 流程接入，缺少素材则明确说明。色温是设计意图，当前接口若只有光源 RGB，需选择受支持的表达并复核成图，不能虚构 Kelvin 参数已设置。

概念稿中的色温、显色指数、灯具功率或照度建议标为设计目标/暂拟条件。没有灯具资料和实际照明计算，不能把 lux、CRI 等数值写成测量或验证结果；Blender 的灯光参数也不等于真实灯具性能。

检查地面、墙面、天花、家具、图形和照明是否支持同一方向。混搭可以保留，但要有明确的共同关系；已有硬装未改变时，不因套配方把它全部替换。发现风格漂移，先定位造成冲突的具体表面或物件，再做局部修正。

将确定的材料和灯光转交 studio-material-render 执行，先更新 CAD 草案、确认、建模，再出图。技术参数正确不等于观感合适；塑料感、贴图比例或反光异常时加载 studio-realism，回到实际模型与画面检查。
