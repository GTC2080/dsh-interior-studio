# 风格与材料搭配卡

本资料选择性改编自 wuciyouci/interior-design-skill 的风格与材料子技能，采用 MIT。来源版本、原许可证及修改说明见 [来源记录](../../../legal/spatial-design-library/NOTICE.md)。以下是可调整的设计起点，不是施工规范、流行度排名或固定材料清单。

## 先选关系，再选标签

| 方向 | 可识别的形体与材料关系 | 配色与照明思路 | 容易失去的重点 |
| --- | --- | --- | --- |
| 当代简约 / 意式 | 连续基准、整合收纳，木、涂料与石材形成明确主次 | 中性色底、重点物件或少量反差，照明揭示体块而非抹平一切 | 只剩白盒子；接缝、开口和触摸细节缺失 |
| 北欧 / 原木 | 浅木、织物、轻盈构件，自然光与实际生活物品形成层次 | 依据采光平衡明亮背景和局部停留光，保留木材本色差异 | 全场同一种黄色；木纹尺度不真实；浅色材料互相融掉 |
| 日式 / Japandi | 模数秩序、低重心、木与纸/织物，留白有具体用途 | 让漫射光、框景和表面触感共同形成安静感 | 把日式等同于榻榻米或把所有家具压低，忽略使用者 |
| 侘寂 / 自然大地 | 克制轮廓、矿物表面、织物与自然不均匀性 | 低饱和材料有冷暖和粗糙度差异，暗部仍能读到形体 | 把“自然”做成随机噪声；全场灰泥；磨损没有使用原因 |
| 奶油 / 轻法式 | 柔和体块、适量线脚或框景，浅色底上保留边缘与厚薄 | 浅色也要有材料和明暗层次，局部强调可兼用对比色 | 所有东西都圆且同色；高光过曝；软体变成光滑塑料 |
| 中古 / 复古 | 家具比例与轮廓、暖木、皮革/织物及局部金属共同表达年代感 | 选择有依据的主调，重点光支持家具与墙面，兼顾日常任务光 | 只加胡桃木和装饰画；不同年代符号堆砌 |
| 现代中式 | 构架、框景、虚实、自然材料与当代使用相结合 | 从地域、业主偏好与空间活动选择色彩，不默认红木或山水图 | 符号贴满墙；家具与通行尺度为造型让路 |
| 经典 / 新古典 / Art Deco | 先明确选用的是古典对称与线脚，还是几何节奏与装饰对比 | 按完整构图组织装饰、灯具与材质，可克制也可浓烈 | 把几种体系混为金色、大理石与水晶灯的堆积 |
| 工业 / 粗野 | 构造表达、矿物/金属与温暖接触材料形成对照 | 局部明暗强调肌理，工作区域仍满足实际视觉任务 | 黑顶、水泥和裸管成为模板；用粗糙度掩盖建模不足 |
| 沿海 / 乡村 / 地中海 | 根据具体地域选择抹灰、木、陶土、编织及开口关系 | 自然光、地方色彩与生活物品共同组织，蓝白不是必选 | 每个开口都做拱形；无依据地加入异地符号 |
| 混搭 / 波西米亚 | 不同材料和物件由共同色调、比例或重复母题连接 | 先确定视觉主次，再让局部有变化，保留活动空地 | 混搭变成无关物品堆积，缺少整体秩序 |
| 主题商业 / 叙事展陈 | 图形、实物陈列、入口与空间轮廓服务同一主题 | 按品牌和观看距离设计识别层级，用光突出真实重点 | 住宅模板生搬硬套；牌子堵入口；图文被粗略凸成实体 |

风格可以交叉，材料由现状和用途约束。不要将“经典已过时”“浅木必须配某一色温”等意见作为硬条件。客户有明确偏好时，以客户目标为准。

## 材料要说到可制作的层级

把笼统“木质”细化为当前能表达的木色、纹理方向、真实覆盖尺寸和表面处理；“石材”说明纹理尺度、哑光/抛光、拼接方向与边缘。没有原始素材时，建议与实际可用资源分开列出，不冒称某种纹理已经存在。

| 表面 | 要共同考虑的关系 | Blender / 工程核对 |
| --- | --- | --- |
| 地面 | 大面积底色、铺装模数、入口与家具的尺度关系 | 以米制重复纹理，检查木板/砖缝尺度和方向；不能只缩放颜色图 |
| 墙与柜 | 大面、分缝、开口、门板、台面边缘的统一基准 | 参数构件尺寸与精细模型一致，近景能看见实际收口 |
| 石材与金属 | 高光、反射和相邻哑光表面共同形成层次 | 金属身份、粗糙度与照明分别核对，避免用发光模拟金属 |
| 织物与软体 | 轮廓、承托、接缝、压缩与纤维尺度 | 先有可信体积，再处理图像、法线与粗糙度；不默认所有布料都有可见编织 |
| 图形与印刷 | 观看距离、字体、色彩、原稿与裁切轮廓 | 平面设计与实体安装分开验证，明确原创示意或待替换素材 |

配色比例用于组织视觉主次，不是 CAD 面积或像素验收指标。可以先确定主背景、辅助材料、识别重点，再根据视图、光照与实际表面积调整，不强制套 60/30/10。

## 光照不能由风格名一键决定

结合环境光、活动/工作光与重点光的功能；它们可以来自同一灯具系统。说明光源位置、方向、照射对象及软硬关系，不机械要求三种灯或固定暖光。

先在代表局部用现有渲染能力试验，保持曝光和相机可比较。浅色发白时区分灯光、曝光、反射与基础色问题；木材发灰时检查光源色彩、白平衡与邻近反射，不能直接改木材颜色补偿所有问题。

输出前核对：有没有相互冲突的形体语言；所有物件是否被同色同材吞没；材质细节是否符合观看距离；照明重点是否与品牌/使用重点一致。只修改影响本轮目标的项，沿用 CAD 与版本确认。
