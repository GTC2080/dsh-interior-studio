# 审美与视觉评审

这是按需使用的设计方法与参考库，不是自动审美评分模型，也不是固定装修风格。整体意图和气质不清时加载 studio-design-concept；比例、主次和空间序列问题加载 studio-spatial-composition；材料、配色和照明是否协调使用 studio-interior-style。按当前问题选择，不将所有库一次展开。

需要通用审稿方法时读 [设计原则与证据卡](references/design-principles.md)，字体、对比或阅读距离有问题时再读 [文字与色彩](references/type-and-color.md)。这些资料改编自公开设计技能，已去除原项目的浏览器、安装器、遥测与专用工具流程。像塑料、玩具或表面失真时用 studio-realism 定位形体与成像原因，不只追加审美形容词。

## 审查实际设计

先读取客户语境、受众、使用目的、固定尺寸与允许改变的区域。分清局部精修和整体重设计：前者保持已有视觉系统，后者重新组织整体语言，但都保留事实与工程约束。已有清楚要求时直接执行，不把专业术语问卷交给客户。

使用已经制作的立面稿、完整正视图、斜角和代表性近景。只有文字说明、对象数量、面数或工具完成状态时，视觉质量仍未评估。先写整体设计判断，再查尺寸和技术检查结果，避免“都没报错”提前影响审美结论。

每个判断指出画面位置和具体依据，按以下方面比较，不作空泛的“高级、简洁、美观”打分：

- 识别：第一眼看见什么，品牌、入口或功能是否清楚；主要信息和次要信息是否争抢。
- 语境：构图、字体、图形与材料是否属于这项需求；换一个无关客户是否仍原样成立。
- 比例：整体、开口、招牌、留白和装饰的尺度是否协调；远、中、近三层是否各有明确内容。
- 统一：建筑轮廓、图文、材质与灯光是否使用同一套语言；细节是否支持主题，还是彼此无关。
- 工艺感：板厚、边缘、转角、拼接、纹理比例、图形映射和照明是否经得起近景；不要用增加面数或高分辨率代替。
- 克制与辨识：有主题但不堆砌，有留白但不空洞；极简、装饰性和童趣等都只是选择，不能强套单一品味。

把最影响本轮目标的1–3个问题变成修改动作，说明修改部位、预期可见变化和复核视角。只改对应部分，重新看完整稿；两版只有颜色或构件数量不同，应重新探索构图。参考资料用于提取关系与设计思路，不照抄照片、版式或品牌素材。

## 形成可检索的参考思路

为本轮实际有用的参考写小型证据卡：公开来源、适用语境、观察到的特征、为何有效、可迁移的关系、不能照搬之处。保存有用的选择和对照图即可，不抓取整站、不积累无用截图，不因参考库扩大就全部加载。没有可靠参考时先做原创方案，不能伪造来源。

审美筛查与 studio-space-review 的几何/通行审查分别记录。用户决定是否喜欢和是否优于原设计；Agent 负责呈现真实差异、缺项和取舍。通过检查后仍需按 studio-material-render 与原生确认流程发布当前版本的1080P图。
