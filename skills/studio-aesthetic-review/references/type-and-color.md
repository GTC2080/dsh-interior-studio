# 文字、色彩与观看距离

参考来源与许可证见 [NOTICE](../../../legal/aesthetic-library/NOTICE.md)。本资料保留信息层级与视觉验证的方法，不将网页字号或响应式规则强套到物理招牌。

## 先分角色，再选字体

先列需要的文字角色：主品牌、活动/周年、功能名称、说明或导向。通过字重、大小、间距、位置与留白一起建立层级；同一级别保持一致。尽量少用字体，但不为了“统一”让所有内容都没有主次。

字体应符合项目语境，不能每个项目都用默认字形。验证实际可用字库、中文缺字和回退；字形转网格后重看笔画、内孔、标点与对齐。没有正式Logo时可以制作明确标注的原创文字方案，不能冒称官方标识。

## 在实际距离看清楚

用完整正立面查看远景识别，将1080P图缩小到大致观看大小，检查第一眼是否读到主信息。再看近景是否因过细、过密、发光、反射或低对比而难读。输出尺寸变大不能修复错误的文字比例。

中文和数字按实际字体调整间距，不能盲目使用固定字距。文字太挤时先处理内容、承载空间与主次关系，不直接拉伸字形来塞满底板。立体字的厚度、底板、连接件与灯光要服务阅读和整体比例。

## 颜色有明确角色

分别选择主要表面、辅助材料、主信息与重点色。用实际颜色关系建立识别和层次，不让所有部位都成为强调色；也不要将低饱和、奶油色或深色自动等同于高级。

对照没有复杂灯光的基础稿与正式效果图。若前者清楚、后者发白，应修曝光/材料/灯光；若基础稿已无层级，应修改平面设计。检查纹理尺度、拼接和倒角时，保留与整体相同的视觉语言。

复核记录应指向具体图稿位置和可见变化；不能仅写“对比通过、排版高级”。可读性验证不等于现场照度、标识或无障碍法规认证。
