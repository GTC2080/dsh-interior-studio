# 空间视觉设计

用户给出尺寸与用途，并不等于已经给出了设计。承担视觉推导与实际制作，不让用户填写专业设计术语，也不把尺寸正确或多加几件装饰当作完成外观设计。

## 明确本轮设计任务

读取当前工程及客户描述，分开记录硬尺寸、开口/通行、已有内部布局、品牌内容、受众与使用距离。自由创作只在允许改变的区域内进行。来源不清的尺寸保留为假定；未经允许不改变入口、标高和其他已确认部分。

从客户材料中提取应传达的气质、使用场景和识别内容，再形成简短的设计主张。必要时检索公开品牌或同类空间资料以理解语境，记录来源，不将参考图冒称为客户原稿或原创。客户限制外传的文件和页面不得上传；没有正式Logo/原画时，文字与原创示意应明确标注身份。

整体方向尚未形成时加载 studio-design-concept；需要空间与立面比例推导时加载 studio-spatial-composition；风格、材料与灯光搭配使用 studio-interior-style。只读取本轮需要的方法，局部已有明确要求时直接沿用原设计语言。

## 先做视觉方案，再深化实体

1. 先在真实宽高比例中设计完整立面或饰面，保留开口、周边、视线和安全区。比较两个有实质区别的构图方向；区别应体现在整体比例、识别层级或图形语言，不能只是换颜色、挪矩形或增减木条。
2. 明确第一眼的主信息、近处的次信息和辅助图形。让品牌、建筑轮廓、周年/活动信息、材料与照明服务同一主张。留白要有意图；空白画面、几何占位和反复的圆片方块不能冒充已设计的图形内容。简洁不等于缺少设计。
3. 按真实观看距离验证文字大小、字重、间距、颜色对比和背景。检查中文缺字、字体替换、字形风格与排版对齐；将画面缩小看是否仍能识别重点。字体或Logo不是越大越好，不能靠发光或厚底板挽救失衡的比例。
4. 实际制作可查看的平面设计稿，包含完整轮廓、文字和原创图形。优先复用当前环境已有的矢量、字体与图像能力；可保存SVG并转换为图片，或使用随包Blender输出正交设计板。先探测已有能力，不安装新软件，不重写图片编码器。制作方法应支持真实图形与排版，不因会画盒子就把平面设计变成堆积实体。
5. 加载 studio-aesthetic-review 比较实际方案，按需读取其参考库：是否符合客户语境，是否有清楚的视觉中心，是否有统一的图形语言，材料和光是否合理，尺寸与净空是否满足。没有达到本轮目的就修改图形稿；不要把仍像占位的方向直接批量建模。需要用户做风格选择时提供实际图稿与差异，不只给形容词。
6. 选定方案后加载 studio-detail-modeling 与 studio-material-render，将实体轮廓、图形饰面、文字、灯光及安装做成同一个工程。印刷层使用图像或矢量饰面；真正需要厚度、内腔、收口、支架与连接的部分建模。保留图形来源和物理纹理比例。
7. 先核正视的构图和可读性，再看能显示厚度、材料、灯光与入口的斜角。使用正式1080P图检查过曝、裁切、遮挡与图形映射；缺图形或比例失衡时回到设计稿，不能靠换机位掩盖。检查与确认仍走原生草案、版本与审查流程。

## 交付与评价

保留有用的方案对照图和选定稿，标注原创示意/待替换素材，其他试验图与脚本及时清理。按客户目标和实际可见特征说明取舍；审美优劣由用户判断，不自行宣布超过专业设计师。图形设计、几何与空间检查分别给出证据，不能互相代替。
