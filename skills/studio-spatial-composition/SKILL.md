# 空间与立面构图

从完整平面、立面和人进入空间的过程判断主次。先明确本轮希望被识别的入口、活动、物件或信息，再组织轮廓、开口、材料和光。局部精修保留已经认可的整体关系，不为套用理论重做全案。

按需读取 [构图与案例分析](references/composition-and-precedents.md)，把问题转成可见关系和具体修改。没有通用的“黄金比例通过”或“必须三个材质”标准；比例系统只在适合本工程时提供一种组织方法。

使用真实尺寸的 CAD 草图检验构图，在一致视角中比较整体与代表局部。门头、家具或饰面改变都先更新 CAD，再进入正式三维与渲染。正视有秩序不代表斜角、入口和背面也成立。

概念 SVG 的画布像素比例不能证明打印比例；画布与纸张宽高比不同，也不排除放入留白图框后按比例打印。只有已经设置并核对物理纸张尺寸、绘图区和实际几何映射，才标注“1:50 @ A3”等比例；否则标为概念示意、尺寸用于讨论。新增开口和节点尺寸列为建议，不冒充客户确认或正式 CAD 验收。

美观与几何可用性分别核对。动线、门窗开启、触达与支撑按 studio-space-review 和保存的 constraints 检查，不能以视觉平衡为由改变锁定尺寸、移动入口或删掉必需内容。把结果交给 studio-aesthetic-review，按实际画面说明得失，不把自评分当成客观结论。
