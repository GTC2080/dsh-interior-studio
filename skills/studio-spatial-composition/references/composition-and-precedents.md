# 构图关系与案例提取

本资料选择性改编自 Abhinav Bhardwaj 的 Skills-Architects / design-theory，采用 MIT。固定版本和原许可证见 [来源记录](../../../legal/spatial-design-library/NOTICE.md)。省略未经核实的历史尺寸、法规和工程阈值，不把宏观建筑手法直接当成装修规范。

## 用关系定位问题

| 关系 | 在实际稿上观察什么 | 可以尝试的修改 |
| --- | --- | --- |
| 比例 | 整体宽高、开口、实墙、招牌与人的尺度是否相互协调 | 沿既有基准调整允许改变的区域，先看整体剪影再做细节 |
| 均衡 | 视觉重量是否过度偏向某一侧或某一高度 | 对称可表达秩序，非对称也可通过体量、明暗、留白获得均衡；不自动镜像一切 |
| 节奏 | 重复、间隔、渐变是否帮助分区与行走 | 用同一模数建立基准，在确有功能或叙事理由的地方变化，避免随机缩放 |
| 主次 | 第一眼是否能辨认入口、主信息与次信息 | 用位置、尺度、深度、材料或光建立重点，不让每个物件都发光或都放大 |
| 统一 | 平面、立面、图文、家具与灯光是否说同一种语言 | 从共享几何、材料或工艺中选合适的联系；不强制所有地方同色同材 |
| 空间序列 | 从外部到入口再到停留点是否有清楚的观看与活动顺序 | 调整允许改变的展示方向、框景和疏密；通路与净空由实际几何检查保障 |

用“这个招牌底板盖住了入口上方的连续轮廓，缩小底板并把文字对齐到开口基准”这样的描述，代替“再高级一点”。修改必须绑定可改变部位，保留尺寸和原有事实。

## 从相关案例学方法

1. 先写当前设计问题，再选少量有相似用途、尺度、材料或设计目标的案例，不按知名度拼贴。
2. 记录真实来源、已看到的图和已知项；没有证据的尺寸、造价和作者身份不补写。
3. 分析空间组织、进出路线、主次、构造与材料交接，以及光怎样影响体验。技术性能有可靠数据才引用。
4. 写成“在什么条件下，采用什么策略，为什么适用”，并说明不能迁移的气候、尺度、预算、文化或安装条件。
5. 在本工程 CAD 中重新推导，检查总尺寸、使用关系与制作能力；不用案例照片证明本工程已经实现。

## 复核方式

完整立面检查视觉主次与开口，平面检查组织与动线，人眼视图检查进入和停留体验，代表近景检查材料与接缝。每轮选最有影响的问题，使用可比视图复核。完整视图范围保存到 constraints.views；不能靠换角度或删主体掩盖缺项。
