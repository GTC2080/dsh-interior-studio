# 从可见问题定位真实感原因

先问当前方案希望呈现什么，而不是默认照片级写实。风格化、童趣与简洁都可以保留。读取当前 CAD、模型版本、材质和机位；只有结构摘要而没有图片时，记录数值问题或待验证假设，不能声称已目视判断。

| 观察到的问题 | 先核对的证据 | 优先处理的层 |
| --- | --- | --- |
| 看起来像方块、轮廓太硬 | 真实外形、剖面、倒角、开口和中距离剪影 | 用 studio-detail-modeling 修正形体，选合适的制作方法 |
| 细节不少但像玩具 | 整体比例、板厚、构造分件、接缝与观看距离 | 先核比例与大中尺度构造，不再无目的细分 |
| 同色、发白、像塑料 | 实际材质节点/贴图、粗糙度、金属属性、光照与曝光 | 固定机位隔离表面和光的影响，再按 studio-material-render 修改 |
| 木纹、石纹或织物不对 | 真实覆盖尺寸、方向、UV、重复性与模型缩放 | 修映射和素材，不能用颜色变化掩盖尺度错误 |
| 悬浮、缝隙、穿插或阴影不合理 | 实际网格、被保存的连接与支撑要求、光源位置 | studio-space-review 检查真实关系；不能只加阴影假装接触 |
| 图片好看但图纸/模型对不上 | CAD、模型、饰面、相机和图片的实际来源版本 | 回到工程版本链修正，不用二维修图代替三维修改 |

使用一个能暴露问题的局部和对应整体视图，先验证主要原因。固定相机、曝光与比较尺度，修改相应变量，再看整体是否受到影响。必要时用中性材料或简化照明排查，但它们只是临时诊断，不覆盖正式工程的已确认状态。

制作路线不清时读取 studio-detail-modeling 的 [形体与修改器](../studio-detail-modeling/references/shape-and-modifiers.md)；参考图量比例时读取 [多视图与比例](../studio-detail-modeling/references/reference-proportions.md)。这两份资料改编自有 MIT 许可的建模技能，工具调用已适配当前插件，不假定存在其他插件的工具。

正式修正先经 studio_refine 回写 CAD 草案并检查，确认后建模和出图。仅机位修改沿用现有依赖与局部重渲染，不重做未变的模型。读取实际新图，同时核对几何与版本；记录解决了什么、还差什么、哪些尚未评估。只清理本轮无用试验资源，不手动删正式版本引用的模型和图片。
