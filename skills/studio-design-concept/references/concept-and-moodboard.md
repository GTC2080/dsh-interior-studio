# 概念、参考与方案迭代

本资料改编自 Gu Jun / arch-skills.com 的概念引擎及意向板迭代方法，采用 CC BY 4.0。固定版本和修改说明见 [来源记录](../../../legal/spatial-design-library/NOTICE.md)。已移除资管行业规则、固定比例、固定几何和“自评分上涨即证明改善”的判断。

## 把设计主张落到空间

从客户行为与场景出发，依次说明“希望传达什么 → 什么可见关系表达它 → 用什么空间手法实现 → CAD 中哪里改变”。可以从地域、材料、活动或品牌图形中取意，也可以直接由功能组织形成概念。避免先画一个常见造型再补故事。

| 客户的表达 | 可以探索的空间关系 | 需要核对的约束 |
| --- | --- | --- |
| 想让人愿意走进来 | 入口向内的连续视线、层次递进、停留点放在路线侧面 | 净宽、开启、无障碍与实际使用要求以项目已知条件为准 |
| 产品很多但不要像仓库 | 陈列模块有主次、局部留空、连续基准与变化密度 | 数量、取放范围、柜深和补货路线 |
| 希望有亲切的故事感 | 局部框景、可辨认的尺度变化、统一图形母题 | 品牌素材来源、读字距离、儿童或成人的使用情境 |
| 简洁但不能单薄 | 用厚薄、深浅、开口和材料接缝形成层次 | 总尺寸、真实构造、制作预算与维护 |

这些是发想路径，不是所有项目的固定布局。将最终采用的关系写成能落到对象与视图上的描述，不要求客户提供坐标。

## 使用意向板而不照搬

先用少量相关参考建立共同语言，通常包含整体气氛、形体关系、材料/灯光和代表局部。记录公开来源及实际观察到的内容；不能访问的图不写成已看过。公开可见不等于可将图片重新打包，客户原件也不因做参考就获准外传。

每个有用案例保留：适用场景、观察到的做法、想迁移的关系、不适用之处。参考应匹配规模、用途或设计目标，住宅、门店与展陈可借鉴关系，但不能照搬承载、消防、成本或施工数值。

把主张收敛到少量可辨认的关键词，并写出对应的形体、材料或照明动作。用户说喜欢“温暖”时，可以比较偏自然采光与浅木、偏包裹照明与织物的不同表达，不能直接认定某个色温或风格是唯一答案。

## 比较真实方案

两种方向应在空间组织、立面比例或识别方式上不同，而不只是换颜色。用同样的尺寸边界、观看方向和近似表现预算展示，标明原创示意、待替换图像与未知工艺。概念预览不能标成已确认施工图。

选定方向后不反复改设计主张。每轮记录最影响目标的问题、修改动作、对应 CAD 版本和待复核视角；上一轮未解决的问题仍保留。可以用结构化描述保持评价尺度一致，但模型给自己打分不能证明审美改善。比较实际画面与使用关系，用户偏好和技术检查分别记录。
