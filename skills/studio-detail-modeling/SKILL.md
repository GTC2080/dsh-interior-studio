# 精细化建模

把已有方案做成轮廓可信、结构有层次、近景也能检查的模型。细化依据来自用户意图、已确认尺寸与实际资料，不从某个案例复制整套构件；模型数量和面数增加不能单独证明质量提高。

## 确定本轮要变细的地方

先读取 studio_context，明确当前正式版本、待确认草案、权限和可用模型接口。意图不清时加载 studio-design-brief，用普通语言澄清影响本轮修改的条件，不要求用户提供建模术语。

把对象分为主要轮廓与比例、实际构造与连接、表面与微小细节三层。列出本轮真正影响辨识和使用的特征、保持不动的尺寸/承托点及仍缺少的资料。先做一个有代表性的局部，确认制作方法可用后再扩展；不要先把粗占位复制满全场。

先确定表达方式：实物需要体积与构造；印刷画面需要图形、版式、真实比例与来源；裁切立牌需要可信轮廓、板厚、底座/背撑和固定关系。不能把所有图形都转成圆盘、方块或凸起文字。缺少品牌原稿时保留明确占位，仍应满足外轮廓、支撑和占地要求。平面图形和材质可用适合的矢量/图像方法制作，实体和安装关系由几何表达，两者需要对齐。

为代表性局部写出可见的验收特征，例如内腔与板厚、轮廓连续性、收口/拼缝、材料尺度或图形层次；按本对象选取，不固定套用部件清单。整体、中景、近景分别检查辨识度和细节，局部样片仍过曝、轮廓错误或像占位时先修正，不批量复制。参数接口表达不了时使用实际 Blender 建模，增加面数或贴图数量不是验收目标。

按用户已表现出的行业经验解释做法。熟悉装修和制作的用户可以直接讨论板厚、收口和节点，保留他给出的规格；不熟悉这些概念时，用“转角更柔和、孔里有真实侧壁、底部确实贴地”等结果解释。助手承担几何、软件和导出的推导，不重复教已有经验的人量尺。缺少的技术参数提出有依据的建议，用户只看方案时先简短说明主要改变和检查方式。

## 选择能表达真实形体的方法

按对象选择方法时读 [形体与修改器](references/shape-and-modifiers.md)，用参考图还原比例时再读 [多视图与比例](references/reference-proportions.md)。这些方法适配本插件的随包 Blender、CAD 草案和真实审查，不要求另装配套插件。不要把其他工具库中的名称当作当前 SDK 已有能力。

- 需要明确尺寸和开口的结构继续使用参数构件；自由曲面、连续截面、沿线造型、复杂切孔或多材质装配使用随包 Blender。不同方法可以共存，不为导入精细模型重绘并丢弃整场参数结构。
- 根据形体选轮廓旋转、曲线扫掠、轮廓拉伸、布尔开孔、实体厚度或局部细分。倒角只处理边缘过渡，不能代替缺失的构造；“平滑着色”也不能修复棱角明显的轮廓或错误法线。
- 应有厚度、开口、凹槽、分缝和内壁的地方做真实几何。印刷内容使用有来源的图片饰面，不能把平面图案凸成实体，也不能用阴影、贴图或一块封板冒充真实孔洞和内部结构。
- 细节随观看距离和用途安排，避免不可见的过度细分。重复部件可复用制作方法，需要单独修改的部件分别导入。来源不明或未提供的品牌、产品和装饰原稿保留缺项，原创示意须说明。

需要实际制作和导出时，读取 [Blender 制作与回写](references/blender-roundtrip.md)。该资料包含运行环境、尺寸检查、GLB 限制和待确认草案的正确更新方式；不要凭记忆猜路径、参数或执行结果。

## 同时检查几何与画面

1. 制作前记录锁定尺寸、关键位置和对象 key；完成后比较实际世界外包络、标高和未要求改变的构件。不能靠非等比缩放、放大公差或删掉部件让审查通过。
   圆角或曲面处理也应保持已确认的总尺寸；明确的最大尺寸是上限，不把“没超过上限”当作满足另一项精确尺寸。
2. 用真实网格核对本轮声明的细节：曲线轮廓是否有明显折面、内腔是否真的打开、厚度是否存在、穿插是否有装配依据。根据对象选截面、射线或局部测量，不把一个任意外包盒测试当作所有曲面的验收。
3. 用 studio_review 检查参数结构与需求的尺寸、数量和连接。导入模型的 CAD/数值尺寸是包络近似，精确曲面接触和支撑不可因此宣称通过；未评估项保留并说明。
4. 局部素材先经 studio_refine 回写 CAD 草案。同一编号替换保留原对象和组合；按最新 drawingId 用 studio_preview 对代表部件复查实际网格和相关连接，再针对失败对象修改草案。门头左、右或柜内不同承托分开声明，不能用整组连通替代单处检查。右侧「草案预览」本地查看正视、俯视、斜视或已保存的相机；同一保存机位适合前后比较。studio_preview 只返回数值，没有图片时不要代替用户目视判断。
5. 用户确认后，正式任务先生成同版本五视图图册再建模；回读 cadAudit、正式版本与 meshAudit，才按 studio-material-render 出整体与近景。形体、材质和灯光修改重复 CAD → 三维 → 出图；仅机位改变按changedViews复用已校验模型，不直接修改发布的 blend。实际读取图片检查轮廓、可见细节、材质尺度和明暗；文件输出、平滑着色或网格通过不能代替目视审查。
6. 不达标时先定位是几何、表面、灯光还是遮挡造成的，只修改对应部分并复查。局部试图须标为试验，只有通过当前适用性核对的正式工程图片才能交付；复用时保留实际生成版本。

“底部看起来稳”与实际抗倾覆不同。没有材料、重量、受力和固定方式时，不能仅凭一个底座比例或重心投影就承诺不晃、安全或承重通过；只说明已测的接触与几何条件，保留未验证的使用要求。

## 交付与清理

将精细模型、图像饰面和机位留在正式工程及其版本中，让用户在右侧继续查看、选择和修改。用自然中文说明可见改善与剩余差异，不把示意图说成原稿还原或施工验收。确认资源已入库且不再需要源文件后，清理本轮临时脚本、源 GLB、贴图副本和预览缓存；不删除正式工程资源、已发布图集或版本历史。

## 工具与验证衔接

将代表局部作为实际检查步骤：明确一个构件组、可见细节与用途，先用真实几何和局部图核对厚度、内腔、收口、接触、材质尺度和图文，再扩展重复构件。通过面数或技能数量不能代替这个步骤；保留必备语义，允许经核对的等价造型替换。

## 文字与图形的实际完成

文字先确定读者在哪一侧，再在components.reading中指定towards；默认Z向上，水平文字可指定up。该字段自动求解XYZ旋转，与rotation互斥；不要靠负缩放、镜像图片或反向取景修正字形。需要先算可用studio_geometry(operation=orientation)。右柜朝内与左柜朝内的方向相反，不能复制相同欧拉角。没有声明阅读方向的旧文字仍要从实际阅读面核对。

用印刷代替实体眼鼻、瓦片或细线时，必须制作实际平面稿，经studio_refine.surfaces应用到准确表面与比例；在固定requirements中保存property=representation、expectedText=image_surface、stage=render，绑定相应对象。它允许先确认基础CAD再制作图形，但未应用真实图片会阻止出图。该检查不识别图片内容是否正确，也不把普通占位图称为客户原画。代表局部先看正视和近景，再复制到全场。

定位与返工先取studio_context(detail=index)，再按key/assembly读取detail=objects；不要反复打印完整场景。连接报告保留unresolvedKeys和各片段bounds，优先处理具体缺口和缺失承托。
