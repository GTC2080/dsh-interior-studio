# 按形体选择制作方法

本资料选择性改编自 sixtyseven67 的 dsh-skill-blender-modeling（MIT），其上游为 RobLe3/cc-blender-skill 与 blender-skills contributors。固定版本、原 NOTICE 和完整许可证见 [来源记录](../../../legal/spatial-design-library/NOTICE.md)。不包含上游专用工具、Windows 启动流程、历史脚本或案例模型。

## 先选择能表达形体的路径

| 需要表达的形体 | 可用的 Blender 方法 | 制作后真正核对的内容 |
| --- | --- | --- |
| 板件、柜体、清楚棱线的硬表面 | 明确轮廓与厚度，必要时布尔开口和局部倒角 | 外包尺寸、内腔、板厚、边缘高光和接缝；不默认用细分把棱线抹圆 |
| 连续圆润外壳 | 连续截面/曲面，按目标组织支撑线、倒角或细分 | 求值后的轮廓、特征线、褶皱及锁定尺寸，平滑着色不代替几何 |
| 瓶、柱、盘等轴对称体 | 有尺寸的半剖面绕轴旋转，按需要保留壁厚和底部 | 最大直径、高度、内外轮廓、法线及端部闭合 |
| 型材、轨道、管路、连续收边 | 沿真实路径扫掠截面，检查转弯与端头 | 截面方向、扭转、转角自交、连接和截面尺寸 |
| 重复格栅、陈列单元、拼板 | 有明确原点/轴向的单元，实例或阵列组织 | 数量、实际节距、首尾和总尺寸；闭环需求解，不靠凭空增减间隔 |
| 坐垫、软包和其他柔性体量 | 根据承托和外形组织网格与局部变形 | 压缩、边缘、接缝及真实接触；不是所有软体都需要皱纹 |

圆角、圆弧、偏移与平面轮廓计算优先用现有 studio_geometry，保留尺寸求解和误差，不手写密集坐标。自由形体不适合参数接口时使用随包 Blender；不能把接口缺少某个参数称作引擎做不到。

## 修改器是按目标组织的求值过程

没有适用于所有模型的固定顺序。先说明这一步需要哪一步的结果：例如先得到薄壳再处理实体边缘、先连接镜像缝再平滑、先处理单元细节再复制，或先复制后统一处理交界。它们是可选路径，最终以本对象的求值结果为准。

更改顺序后执行依赖图更新，使用 evaluated_get(depsgraph) 及 to_mesh() 读取最终几何，量世界坐标尺寸、实际轮廓、厚度与连通壳；使用后 to_mesh_clear() 释放临时网格。只读取基础 mesh 或修改器列表不能证明输出正确。接着按 [制作与回写](blender-roundtrip.md) 应用适用的修改器、导出并重开 GLB，检查 Blender 4.5 的实际结果，不照搬其他版本 API。

后台脚本优先使用 bmesh 或数据 API；必须用 bpy.ops 时，确认活动对象、模式和上下文，不能仅因 GUI 中可用就假定后台可用。用局部轴表达长宽厚，使用世界矩阵核对最终朝向；不为了镜头好看改变已经约定的朝向。

逐个闭合连通壳检查法线与有符号体积；一个正向大壳可能遮蔽小反向壳的总量，空腔和开放表面需要区分。无法判定的项保留未评估。清理松散点边不能当作删除内部面；布尔合并也不能替代真实装配关系。

## 接缝不能靠穿插制造通过

区分可视封口、实体接触、连接路径与真实承载。展示模型如确需隐藏搭接，须有明确设计依据、可修改范围与尺寸；回写 CAD 后再按真实表面复核，不把搭接值写成所有项目通用下限。AABB 重叠只是粗筛，不是旋转接口的接触深度，更不是结构安全证据。

使用现有 constraints.supports、relations 与真实网格审查保存和核对本轮范围；失败、超预算和未评估仍显示。不要为了达到单一连通壳、零交叠或“特征数量大于零”等机械指标破坏本来就分件、带空腔或刻意留缝的设计。
