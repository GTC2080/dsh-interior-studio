# 多视图、比例与还原范围

本资料改编自 sixtyseven67 的 dsh-skill-blender-modeling（MIT），来源和上游版权见 [来源记录](../../../legal/spatial-design-library/NOTICE.md)。仅迁移参考分析方法，不包含原插件的标定、拟合或审计工具；工具是否可用以当前 SDK 为准。

## 先判断图片能证明什么

区分带标注的正投影图、透视效果图、现场照片和示意图。图纸中的明确尺寸优先；不能从漂亮的效果图反推不存在的精确尺寸。客户禁止上传的 PDF/原图继续只在获准范围内使用，向模型复述时保留事实、建议与未知项，不附上原件。

每个视图独立记录尺寸基准、方向、比例和已看到的特征。正交并不保证不同页、截图或图片具有相同像素比例；已知长度只能标定其所在图的相应条件。多视图对比先换成实际长度，并核对同一对象和标注口径。

透视校正只可能校正选定平面，不能让一个有厚度和深度的物体全都变成可直接量尺的正视图。不能把同一平面的像素比例套到前后不同深度；没有相机/几何依据时，数值只是估计而非实测。没有可靠标定工具时说明限制，不手算出看似精确的尺寸。

## 从大关系到构造

先核整体长宽高和主要开口，再核不同深度处的剖面、转折与特征线；前视、侧视和俯视相互补充。轴对称走旋转，基本恒定截面走扫掠，变化截面才考虑放样，多体量按构造分件。单张图不足以确定隐藏结构时保留假设，不把类别常见比例当成客户图纸事实。

用同方向的模型正投影视图和参考比较轮廓，同时量 CAD / 实际网格的包络与关键尺寸。轮廓吻合不证明深度、内腔、面感或材质正确；若实际计算了轮廓 IoU，它也只提供该视图和分割条件下的二维证据。没有计算或读取图片不能报数值或冒称已对照。

保留固定要求和来源，不能通过改相机、拉伸模型、删掉附件或放宽公差提高相似度。代表局部在近景检查厚度、内腔与接缝，再在交付距离确认效果；数值核对和画面对照分别给出结果。
